Asset kit

Image prompts for the diagrams

Every visual on the main page can be regenerated as a finished illustration with these prompts. Paste the shared style block first, then one asset prompt per generation. Target model: Gemini (image generation). Each prompt names its output file and the spot it fills on the page.

SShared style block (prepend to every prompt)

STYLE, applies to the whole image: clean editorial infographic on a pure white background. Two-color system: deep navy blue #1C2D5E for structure, lines, and primary text; warm gold #E8A820 as the single accent for highlights, arrows, and emphasis. Light gray #E5E8EF for hairline dividers only. Flat vector look, no gradients, no drop shadows, no 3D, no photorealism. Generous white space. A refined serif for headings, a clean humanist sans-serif for labels. Institutional-document mood with one playful accent, like a well-designed government report that knows it is being read by a human. No watermarks, no logos, no fictional text beyond the labels specified.
