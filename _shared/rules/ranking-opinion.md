# Ranking opinion: how ties between candidate causes break

This file is opinion, deliberately. The threshold in `stages/05_diagnose`
decides whether a cause qualifies; that is arithmetic. Which of two
qualifying causes is PRIMARY is a judgment, and burying a judgment inside
an inventory is how a diagnosis becomes a list. The order below is our
position, stated so a reader can disagree with it.

Apply in order. First rule that separates the candidates wins.

1. **The moved cell outranks the loud quote.** The factor whose scores
   are worst relative to the others is where the application actually
   lost. A cause whose grid signature matches the moved cell beats a
   cause with more quotes attached to an unmoved factor. Reviewers write
   more about what interests them; they score what cost the applicant.

2. **Cause outranks symptom.** When two modes are both present and one
   plausibly produces the other, name the upstream one. A generic
   training plan (mode-05) sitting under a candidate section whose
   trajectory was never argued (mode-06) is a symptom of the same
   omission; name mode-06.

3. **Targeting outranks writing when the score contradicts the outcome.**
   A decent impact score outside the payline with no substantive weakness
   language is mode-13, not a writing problem. Do not diagnose prose when
   the arithmetic says the application went to the wrong institute.

4. **Structural outranks itemized.** A rigor bullet list (mode-09) is
   cheap to write and cheap to fix; if a structural mode (01, 02, 03, 06,
   10) also qualifies, the structural one is primary.

5. **Reviewer agreement outranks reviewer volume.** A cause named by two
   reviewers in one sentence each beats a cause named by one reviewer in
   four sentences.

If no rule separates them, stage 05 refuses and names both. Two causes
presented as one is the answer this tool exists to avoid.
